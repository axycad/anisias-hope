## Research page split (overview + open trials)
Each CLN form has **two** pages:
1. **Overview** (`clnN.html`) — short intro, Overview / Research & publications / Historic notes placeholders, Other support, and a CTA card linking to open trials.
2. **Open trials** (`clnN-trials.html`) — dedicated list page with empty “Currently listed / recruiting”, sourcing policy, generic ClinicalTrials.gov search tip, and historic placeholder. No invented NCT numbers, drugs, results, or dates.

Nav stays simple: **Research → research.html** (no 28 nav items). Footers match the rest of the site.
